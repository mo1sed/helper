Быстрая вставка на Mac — установка
==================================

Это отдельный маленький помощник к Vice Dolls Helper. Он берёт сообщения из
того же файла приложения и вставляет выбранное в любое поле ввода.

ШАГИ
1. Сначала хотя бы раз запусти само приложение Vice Dolls Helper и добавь
   пару сообщений (чтобы появился файл с данными).
2. Распакуй эту папку куда угодно (например на рабочий стол).
3. Запусти файл "Собрать и запустить.command" двойным кликом.
   - Если macOS спросит про "инструменты разработчика" — согласись, подожди
     установку (несколько минут) и запусти файл ещё раз.
   - Если выскочит предупреждение безопасности: правый клик по файлу ->
     "Открыть" -> "Открыть".
4. В строке меню вверху справа появится значок "VD".
5. Первый раз система попросит разрешение "Универсальный доступ"
   (Accessibility). Открой: Системные настройки -> Конфиденциальность и
   безопасность -> Универсальный доступ -> включи "VDHPaste".
   Без этого вставка работать не будет (это защита macOS).

КАК ПОЛЬЗОВАТЬСЯ
- Нажми Control + Option + V в любом поле ввода — появится меню с папками и
  сообщениями. Выбери сообщение — оно вставится.
- Либо нажми на значок "VD" в строке меню и выбери сообщение оттуда.
- Чтобы выйти: значок "VD" -> "Выход".

ЧТОБЫ ЗАПУСКАЛОСЬ САМО ПРИ ВКЛЮЧЕНИИ MAC
Системные настройки -> Основные -> Объекты входа -> "+", и добавь файл
VDHPaste (появится рядом после сборки).

Важно: это первая версия для Mac, собранная "вслепую". Если при сборке будет
ошибка — отправь мне её текст, поправлю.
